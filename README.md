# МультиМаршрут — демо-сайт мультимодальных маршрутов (ЖД + автобусы) по России

**Живой сайт:** после включения GitHub Pages → https://nicolassavin.github.io/multimodal-routes/

## Что это

Веб-приложение для составления маршрутов по России с поддержкой:

- **Прямых поездов** (включая Сапсан, ночные поезда, дальнего следования)
- **Прямых автобусов**
- **Мультимодальных комбинаций** (поезд + автобус с пересадкой)
- **Опциональных фильтров**:
  - Места в одном купе (для 2+ пассажиров)
  - Только нижние полки

## Как открыть локально

```bash
python3 -m http.server 8080
```
Открыть http://localhost:8080

## Особенности

- Автодополнение городов (30+ крупных городов России)
- Реалистичные демо-данные по популярным направлениям: Москва–СПб, Москва–Казань, СПб–Казань, Москва–Сочи
- Для остальных пар генерируются generic-маршруты
- Фильтры по местам отсекают неподходящие варианты
- Адаптивный современный UI (Tailwind)

## Реальная интеграция (для продакшена)

1. **Яндекс.Расписания API** — расписание поездов, автобусов, электричек (нужен ключ)
2. **Неофициальный API ticket.rzd.ru** (библиотеки `rzd-api`) — наличие мест, типы вагонов, схемы купе/плацкарта, нижние/верхние полки
3. Параметры: `n_down` (нижние), `in_one_kupe` (одно купе)

Демо использует mock-данные, чтобы показать UX и логику фильтров без ключей API.

## Структура

- `index.html` — разметка и стили
- `app.js` — логика поиска, фильтры, рендер маршрутов
- `.nojekyll` — отключает Jekyll для чистого static hosting на GitHub Pages
