# Мультимаршрут Android

Оболочка сайта: https://nicolassavin.github.io/multimodal-routes/

## Сборка APK на Windows (10–15 мин)

1. Скачайте [Android Studio](https://developer.android.com/studio) и установите.
2. File → Open → папка `android` из этого репозитория (или скачайте ZIP репо).
3. Дождитесь **Gradle Sync** (первый раз долго).
4. Подключите телефон: USB + «Отладка по USB» в параметрах разработчика
   **или** запустите эмулятор.
5. Зелёная кнопка **Run** ▶
6. Либо: Build → Build Bundle(s) / APK(s) → **Build APK(s)**.
7. Файл: `app/build/outputs/apk/debug/app-debug.apk`
   Скопируйте на телефон и установите (разрешить неизвестные источники).

В Google Play не публикуется автоматически — для своих сотрудников APK достаточно.
