МультиМаршрут — демонстрационный сервис составления мультимодальных маршрутов (ЖД + автобусы) по России.

В реальном проекте интегрируется с API Яндекс.Расписаний, неофициальным API РЖД (ticket.rzd.ru) и расписаниями автобусных перевозчиков. Проверка мест в одном купе и нижних полок реализуется через детализацию вагонов.
